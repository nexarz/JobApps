# Cover Letters

Drop your cover letter files here as `.txt` or `.md` files.

**Filename format** (used to auto-extract company/role):
- `Product Manager @ Acme Corp.txt` → role: "Product Manager", company: "Acme Corp"
- `Acme Corp - Product Manager.txt` → company: "Acme Corp", role: "Product Manager"
- `My Cover Letter.txt` → title only

Then run: `npm run seed`
